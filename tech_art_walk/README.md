# 從科幻作品導讀未來｜Future Readings

《科技藝術走讀》課程的延伸企劃，收錄陳嘉暐老師與學生於 2024–2025 年製作的六集閱讀與科幻作品對談，以《連結》、《AI 2041》及電影、影集討論 AI、情感、資訊與人的選擇。

[網站入口](https://weisfx0705.github.io/chiawei/tech_art_walk/) · [主專案說明](../README.md)

## 使用方式

1. 選擇左側或上方的集數，閱讀單元簡介與思辨問題。
2. 透過 Spotify 連結收聽對談。
3. 完成每集五題選擇練習，作為課堂討論的起點；切換單元會重設測驗。
4. 在頁面下方查閱指定閱讀書目。

六集主題涵蓋《機械公敵》、《雲端情人》、《楚門的世界》，以及《黑鏡》的〈馬上回來〉、〈全網公敵〉與〈約會程式〉。

## 本機預覽

從儲存庫根目錄執行：

```sh
cd tech_art_walk
python3 -m http.server 8000 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8000/`，按 Ctrl+C 停止。這是單頁靜態網站，不需要 npm 安裝或建置；React、ReactDOM、Babel、Tailwind CSS 與字型從外部 CDN 載入，因此首次載入與正常呈現需要網路。Spotify 收聽也需連網。

## 檔案與維護

| 位置 | 用途 |
| --- | --- |
| `index.html` | 頁面、樣式、React 元件、集數與測驗資料 |
| `pic/` | 各集圖片 |
| `scripts/` | 節目介紹、文字稿與來源連結，供內容整理參考 |

更新集數時，編輯 `index.html` 的 `episodes`；互動題目位於 `QUIZ_DATA`，兩者以 `quizId` 對應。`scripts/` 文字不會自動同步到網頁。圖片檔名大小寫須與程式一致，尤其是現有的 `.PNG` 檔名。

發布時保留 `index.html` 與 `pic/` 的相對位置，隨主專案部署至靜態網站即可。書籍、影視作品及節目內容的權利歸各自權利人。
