# 影視課程島

義守大學電影與電視學系的互動式四年課程地圖。選擇 112–115 學年度入學版本，從八個電影職務探索修課路線，用裝備、角色成長與學分護照呈現學習進度。

[開啟網站](https://weisfx0705.github.io/chiawei/film-island/) · [本機入口](index.html) · [回主專案](../README.md)

## 怎麼使用

1. 選擇自己的入學年度，進入課程島。
2. 點選島嶼或課程，查看學分、年級與推薦職務；也可切換清單版。
3. 勾選已修課程，收集裝備，在「學分護照」記錄博雅、跨域學分與畢業檢核。
4. 選擇「職務路線」或「播放四年成長」，查看從大一到大四的養成示範。示範結束會回到自己的紀錄。

修課紀錄保存在目前瀏覽器的 `localStorage`，按入學年度分開保存，沒有登入、雲端同步或教務系統連線。清除瀏覽資料會移除紀錄；「一鍵還原成大一新生」只重設目前年度。

## 本機預覽

macOS 可雙擊 `open.command`，啟動本機伺服器並開啟瀏覽器，需要已安裝 Python 3。關閉終端機視窗或按 Ctrl+C 即停止。

也可在 `film-island/` 資料夾內執行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8000/`。載入器會透過 HTTP 讀取程式，請勿直接以 `file://` 開啟。3D 地圖需要瀏覽器支援 WebGL。

## 檔案與維護

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 介面、樣式與各面板 |
| `boot.js` | 資源載入、進度與失敗重試 |
| `cohorts.js` | 各入學年度的課程、學分結構與職務路線 |
| `data.js` | 島嶼、職務、年級配色與課程裝備的設計對照 |
| `app.js` | 3D 地圖、修課勾選、學分護照與成長示範 |
| `vendor/` | 隨專案保存的 Three.js 與 OrbitControls |
| `open.command` | macOS 本機預覽啟動器 |

純靜態網站，沒有套件安裝或建置步驟，保留整個資料夾即可隨主網站發布。

`cohorts.js` 為產生後的資料檔；註解提到的原始整理檔與產生工具未包含在此儲存庫。更新課程資料前，應先取得對應來源與產生流程。

## 資料範圍

課程資料依各入學年度四年課程計畫整理，頁面提供官方 PDF 連結。職務路線與裝備是學習導覽及設計詮釋，選修建議不代表每學期必定開課。選課、學分認列與畢業資格仍以學校正式公告及個人修課紀錄為準。
