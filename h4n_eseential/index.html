Film & TV use

你先抓住四件事

這台 H4essential 有很多功能。你在影視二《影視錄音實務》先完成一個目標：把這台新購器材用在拍片現場，穩定接線、確認軌道、戴耳機監聽、完成可帶回後期的錄音檔。

1 INPUT 1 / INPUT 2 是拍片主軸

INPUT 1 可接 shotgun，INPUT 2 可接無線麥克風接收器。兩軌分開錄，後期剪接時比較好救、好平衡。

2 XY 麥克風收環境音

帶出去錄 room tone、街景、空間感、現場 ambience。後期補環境底噪時非常有用。

3 耳機先於信心

你一定要戴耳機確認是否真的收到聲音。不要只看波形，也不要只相信接頭已經插上。

4 紅燈、紅波形、時間跑

按 REC 後，看到 REC 燈亮、波形轉紅、錄音時間開始跑，才算真的開始錄音。

Field workflow

拍攝現場的六步驟

每一次開錄前都照這個順序做。固定流程可以避免忘記開軌、沒插卡、沒監聽、錄完沒回放。

插入 microSD，確認剩餘時間關機狀態下插卡。第一次使用或從其他設備換過來時，先在 H4essential 內格式化。可使用 microSDHC 4 至 32GB、microSDXC 64GB 至 1TB。
準備電源可使用 2 顆 AA 電池，或用 USB Type-C 接 5V 供電。現場長時間拍攝建議用一般行動電源，但要確認是 5V 輸入。
接上麥克風Shotgun 接 INPUT 1，無線接收器接 INPUT 2。若是 3.5mm 小型無線系統，可改接側邊 MIC/LINE IN。
開啟要錄的軌道按 MIC、1、2 的軌道鍵。要錄哪一路，那一路的狀態燈要亮紅；不用的輸入關掉，省電也減少混亂。
戴耳機監聽並調整平衡耳機接 PHONE/LINE OUT。側邊 VOLUME 控制耳機與輸出音量，錄進檔案的聲音由輸入、軌道與 Mixer 設定決定。多支麥克風音量差異可到 Mixer Screen 調整監聽平衡。
錄音、停止、立刻回放按 REC。確認紅燈亮、波形變紅、時間開始跑。停止後用 PLAY 回放，確認沒有沒聲音、爆音、衣服摩擦或無線干擾。
現場口訣

亮紅、聽到、錄到

波形會動不代表正在錄。要看到 REC 燈與紅色錄音狀態，也要用耳機聽到乾淨聲音。

32-bit float 給後期更多餘裕，但它不會幫你解決沒插好、沒開軌、無線沒電、衣服摩擦或麥克風位置太遠。

Inputs

影視系最常用的三種使用情境

你可以把 H4essential 當成拍攝現場的「小型分軌錄音機」。先理解不同輸入代表不同拍攝任務，再去理解選單。

情境 接哪裡 你要怎麼用 注意事項
Shotgun 麥克風 INPUT 1，通常 XLR 用於對準演員或訪談主體，盡量靠近聲源，不要只靠後期救。 電容式 shotgun 需要供電時，才開該軌 Phantom +48V；不需要的設備不要開。
無線麥克風接收器 INPUT 2，依接收器輸出選 XLR/TRS 或轉接 角色身上的 lav 收對白，適合和 shotgun 同時分軌記錄。 先聽衣服摩擦、RF 雜訊、接收器電量。線路訊號盡量用 TRS，麥克風訊號用 XLR。
內建 XY 機身上方 MIC 錄環境音、空間聲、room tone、街景 ambience，供後期貼補。 手持時不要摩擦機身。戶外要上防風罩。錄環境音時，請現場安靜 30 至 60 秒。
3.5mm 小型系統 側邊 MIC/LINE IN 可接小型無線、領夾麥或 RODE 類型 3.5mm 訊號，作為補充方案。 使用 MIC/LINE IN 時，內建 XY 麥克風不能同時使用。需要 plug-in power 的小麥克風要開對應設定。
Track routing

檔案配置先看這兩件事

你在現場接 INPUT 1 和 INPUT 2 時，先決定它們要分開當兩支 mono 麥克風，或組成一組 stereo pair。這個設定會影響後期拿到的檔案形態。

1&2 Link Stereo 會把 INPUT 1 / 2 組成一組立體聲

路徑：Input Settings → INPUT 1 或 INPUT 2 → 1&2 Link → Stereo。開啟 Stereo 後，INPUT 1 會成為 Left，INPUT 2 會成為 Right。官方 Quick Tour 也寫明，Stereo Link 後 Track 1/2 會錄成一個 stereo file，Track 1 在 L，Track 2 在 R。

用法判斷：你接的是一組 stereo 麥克風或 mixer 的左右聲道時，才適合開 Stereo。若 INPUT 1 接 shotgun、INPUT 2 接無線 lav，要保留兩支麥克風的獨立後期處理空間，1&2 Link 請維持 Off。

Shared settings Link 後有些設定會一起走

官方手冊特別寫到：INPUT 1/2 Stereo Link 後，Lo Cut 會共用相同的截止頻率。這代表你調 80Hz、160Hz 或 240Hz 時，這組 stereo pair 會套用同一個低切設定。

拍片現場的記法：shotgun + 無線 lav 通常是兩個角色任務，分開錄比較安全；stereo pair 才用 Link。看到「1&2 Link」時，先想到檔案與左右聲道配置，再去想其他音量設定。

新版 Firmware 的 Gain 要另外分清楚

H4essential 原始設計使用 32-bit float 與 Dual A/D Converter，官方規格曾寫 Input Gain「Adjustment unnecessary」。Firmware 2.0 之後，官方補充手冊新增「Setting input gain」，你可以在 Mixer Screen 針對每一軌調 Gain。

  • 操作：Home Screen → 按 MIXER → 選要調整的軌道 → ENTER → 用轉盤調 Gain → ENTER 確認。
  • 快捷：在 Home Screen 長按要調整的軌道鍵，也可以進入該軌 Gain 調整。
  • 如果你的機器看不到 Gain，先檢查 Firmware 版本；官方 v2.30 補充手冊仍把這項列在 Version 2.0 新增功能中。
  • 錄 MP3 時，補充手冊提醒要讓波形保持在虛線範圍內，避免錄音檔 clipping。
Level concepts

你要分清楚四種音量概念

H4essential 經過 Firmware 2.0 更新後，多了每軌 Input Gain。你要把「Input Gain」、「Rec Source」、「Mixer Volume」與「Output level」分開看。

Gain 每軌輸入增益

Firmware 2.0 之後可在 Mixer Screen 調整每一軌 Gain。這是輸入訊號進錄音流程前的增益設定。32-bit float 仍給你後期餘裕，但現場仍要用耳機與波形檢查。

Rec Source 錄原始輸入或 Mixer 後電平

Rec Settings → Rec Source 可選 Pre Mixer 或 Post Mixer。Pre Mixer 會錄輸入聲音本身；Post Mixer 會使用 Mixer Screen 調整後的電平。

Mixer 各輸入的監聽平衡

Mixer Volume 會影響你在耳機聽到的比例，也會影響混合 stereo 檔。它和 Firmware 2.0 新增的 Gain 要分開判斷。

Output 耳機與外送音量

側邊 VOLUME 是 PHONE/LINE OUT 的監聽/輸出音量。它調大只代表耳機更大聲，不等於錄音本身變大聲。

Phantom +48V 要先問三句

  • 這支麥克風是否需要 phantom power？電容式麥克風常需要，動圈或某些無線接收器通常不需要。
  • 我有沒有只開需要供電的那一路？H4essential 可以針對 INPUT 1、INPUT 2 分別開關。
  • 接的是不能吃 phantom 的設備嗎？不相容設備不要開，避免損壞。

戶外與手持的兩個提醒

  • 風聲或靠嘴太近導致 overload，可先移開麥克風或開 Lo Cut。Lo Cut 可設定 Off、80Hz、160Hz、240Hz。
  • 手指摩擦機身會被 XY 麥克風收進去。外出錄 ambience 時，最好固定在腳架上或保持手不動。
Power & media

電源、卡片、交檔

這些細節最常讓作業失敗。請把它當成器材助理的基本功：電源要穩，卡片要能錄，檔案要能交。

建議設定

  • Sample Rate：影視課建議先用 48 kHz，便於和影像流程對齊。
  • Bit depth：H4essential 錄音為 32-bit float。後期容錯較高，前期仍然要戴耳機聽、開錄後檢查。
  • 檔名：錄音檔名依日期與時間產生。請把場次、鏡號、take 與錄音時間記在場記表。
  • 下課交檔：USB 選 File Transfer，接電腦後像外接磁碟複製，不要只交混音檔，分軌檔也要保存。

電源安全提醒

  • Type-C 外接供電使用 5V，一般行動電源即可。
  • 輸出規格不確定的高功率充電器先不要接上機器。
  • 若用 AA 電池拍 4 軌加耳機監聽，續航會明顯下降，現場要準備備用電池或行動電源。
  • 不用的輸入、耳機線、過高螢幕亮度都會影響電池時間。
Student handout

錄音前後檢查表

每次作業都照著念一遍。你確認完這些項目，再按下 REC。

開錄前

  • microSD 已插入，剩餘時間足夠。
  • 電池或 5V Type-C 供電已確認。
  • INPUT 1 接 shotgun，INPUT 2 接無線接收器。
  • 需要用 3.5mm 系統時，接側邊 MIC/LINE IN。
  • 要錄的 MIC、1、2 軌道燈亮紅。
  • Phantom +48V 只開給需要的麥克風。
  • 戴耳機確認每一路都有聲音。
  • Mixer 裡每一路監聽平衡合理。
  • 側邊 VOLUME 只調耳機，不當作錄音增益。
  • 戶外錄音已裝防風罩。

錄音中與收工

  • REC 燈亮、波形紅、時間正在跑。
  • 演員講話時耳機聽得到，波形也有反應。
  • 聽到衣服摩擦、風聲、破音時立刻停下處理。
  • 每個重要 take 後做短回放。
  • 錄一段空場環境音供後期使用。
  • 檔名時間與場記紀錄對得上。
  • 收工前確認檔案清單有新檔。
  • 複製檔案到電腦後再退卡或關機。
  • 分軌檔與混音檔都保存。
  • 關機，電池與記憶卡依器材規範收納。

記住這一句

現場錄音要完成一整串動作：選對麥克風、放對位置、開對軌道、聽到正確聲音，然後把可用的檔案帶回後期。
