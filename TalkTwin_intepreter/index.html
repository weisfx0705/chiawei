OPENAI CONNECTION

連接你的 OpenAI API

這是靜態網頁版。Key 只存在你自己的瀏覽器，直接送給 OpenAI，不會經過任何中間伺服器。

⚠️ 使用前請先了解風險
  • Key 存在這台裝置的瀏覽器（localStorage）。清除瀏覽資料就會消失，換一台電腦要重新輸入。
  • 靜態網頁沒有後端可以代為保管，因此 Key 會出現在瀏覽器的開發者工具中，也可能被有權限的瀏覽器擴充功能讀取。請不要在公用或共用電腦上輸入。
  • 請使用可獨立設定額度的 Project API Key，並在 OpenAI 後台設定每月用量上限，萬一外洩損失有限。
  • 所有 API 用量都會計入你自己的 OpenAI 帳單。Realtime 即時語音的費率高於一般文字，長時間開著請留意用量。
  • 離開前若使用的是他人電腦，請按下方的「移除 OpenAI Key」。
🔑 還沒有 API Key？三分鐘申請教學
  1. 到 platform.openai.com 註冊或登入 OpenAI 帳號（與 ChatGPT 帳號相同即可）。
  2. 進入 Settings → Billing，綁定信用卡並儲值（最低約 US$5）。沒有付款方式的帳號無法呼叫 API，這與 ChatGPT Plus 訂閱是兩回事。
  3. 進入 Dashboard → API keys，按 Create new secret key。
  4. 建議選擇某個 Project 底下建立，方便單獨設定額度與追蹤用量。
  5. 複製那串 sk- 開頭的字串——它只會顯示這一次，關掉視窗就看不到了。
  6. 貼到上面的欄位，按下方「儲存並連接」。
  7. 回到 Settings → Limits 設定每月用量上限（建議先設 US$5–10）。

若出現 insufficient_quota，代表帳戶餘額不足；若出現 invalid_api_key，請確認複製時沒有多餘空白。
