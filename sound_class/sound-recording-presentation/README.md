# 同步錄音團隊互動簡報

義守大學電影與電視學系 · 陳嘉暐老師教材編輯 2026

26 頁的靜態 HTML 互動教材，包含訊噪比示意、團隊配置、器材接線、錄音報表與課堂練習。

## 資料夾內容

```text
sound-recording-presentation/
├── index.html                網站入口
├── README.md                 使用與部署說明
└── assets/
    ├── css/style.css         版型與響應式樣式
    ├── js/app.js             換頁、互動圖、試聽、報表與計時器
    ├── images/               原教材圖片素材
    └── manifest.json         素材名稱與來源對照
```

## 部署

將本資料夾中的全部內容上傳至靜態網站主機的公開目錄。
公開目錄必須直接包含 `index.html` 和 `assets/`，並保留兩者的相對位置。

這個網站不需要安裝套件、執行建置或啟動後端。入口檔案為 `index.html`。
所有素材都使用相對路徑，可放在網站根目錄或子資料夾。
主機需以 UTF-8 提供 HTML、CSS、JavaScript 和 JSON，並正常提供圖片檔案。

若平台要求填寫設定：

- 建置命令：留空。
- 發布目錄：本資料夾；若它位於儲存庫內，選擇 `sound-recording-presentation`。
- 單頁應用程式重新導向：不需要。

## 本機預覽

在此資料夾開啟終端機，執行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在瀏覽器開啟 `http://127.0.0.1:8000/`。按 Ctrl+C 停止預覽。
也可直接用瀏覽器開啟 `index.html`。

## 操作

- ← / →：換頁。
- G：目錄。
- N：教師筆記。
- F：全螢幕，依瀏覽器支援。
- 訊噪比頁點擊播放後開始試聽；離開該頁會停止。
- 清單及報表儲存在使用者自己的瀏覽器，沒有上傳服務。
- 音效由 Web Audio 即時產生，沒有另外的音檔。
- 外部影片與來源連結需要連網，其餘教材素材都在資料夾內。

## 編輯

文字與投影片內容在 `index.html`，樣式在 `assets/css/style.css`，互動程式在 `assets/js/app.js`。
更換圖片時，請同步確認 HTML 中的圖片路徑，以及 `app.js` 的 `assets` 素材對照表。
圖片來源與原始識別碼保留於 `assets/manifest.json`。
