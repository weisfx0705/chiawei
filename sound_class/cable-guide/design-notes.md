# 雙視角收線練習頁：設計與驗證

## 教學設計

以「看 → 做 → 收」取代需要探索的八格選單。第一人稱與第三人稱影片具有相同的畫面尺寸、標題層級、播放按鈕和觀看連結，不使用折疊區塊。

整體採紙色底、深色線框、清楚的步驟編號。正圈用藍色、反圈用橘色；影片卡兩張同色，顏色不代表視角優先順序。真人手勢照片是主要教材，不使用生成手勢圖或裝飾性假動作。

內容依序：雙視角影片 → 動手前準備 → 正圈兩格 → 反圈四格 → 正反交替兩格 → 線頭擺放 → 可退式束帶 → 再次放線。

## 保留的內容原則

- 每段一個動作、一句提醒。八張真人影格全部展開，圖片可原頁放大，時間連結回到原片。
- 直接建議可退式束帶，不以學校慣例作解釋。
- 收整照片只作兩端接頭位置參考，不據此認定收線方法或把原照片固定帶誤稱為可退式束帶。
- 收整後兩端留在圈外，不把接頭穿圈來湊齊；根部不硬折。

## 驗證

- 檢查 1440、1024、768、390、320 像素寬度：無橫向溢位，兩個影片框寬高一致；桌面在同一列，兩支都直接顯示。
- 兩支影片 URL、第一人稱從 5 秒開始、切換後只有一個播放器、原封面可再次啟動，均通過。
- 原頁大圖、Esc 關閉、焦點返回原圖片，均通過。
- 停用 JavaScript 仍顯示兩支影片封面、外部觀看連結與完整手勢圖片。
- 本機資產、頁內錨點、八張手勢截圖、可退式束帶用字及無 JavaScript 執行錯誤，均已檢查。

目前頁面只載入 `workshop.css` 和 `workshop.js`，無框架、外部字型、API 金鑰或自動播放的動畫。
