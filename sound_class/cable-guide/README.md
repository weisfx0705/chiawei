# 正圈與反圈手勢圖解

用途：`../15.html` 的手勢教學圖片。

- 使用 OpenAI Image API，模型 `gpt-image-2`，以官方 imagegen CLI 的 `edit` 模式繪製。
- 最終提示詞：`over-hand-prompt.txt`、`under-hand-prompt.txt`；局部修正提示詞：`over-hand-final-prompt.txt`、`under-hand-final-prompt.txt`。
- 原始 PNG：`output/imagegen/over-hand-v3.png`、`output/imagegen/under-hand-v3.png`。
- 網頁用 WebP：`over-hand.webp`、`under-hand.webp`；同一圖像的壓縮版本。
- 視角：面對示範者；畫面左側是示範者右手（取線），畫面右側是左手（持圈）。
- 圖像為 AI 繪製的關鍵姿勢示意，連續動作搭配頁面影片。不得把圖片當作線材的完整三維運動模型。

動作參照 QSC 原廠教學：
- https://training.qsc.com/mod/book/tool/print/index.php?id=1715
- https://www.youtube.com/watch?v=PJjMc-tTksU
- 正圈參考畫面：1:41、1:48；反圈參考畫面：2:03、2:07。
- 圖解使用原影片作姿勢參考，不使用原人物身分。
- 經使用者要求，另加入 QSC 1:41、1:48、2:03、2:07 的真人示範截圖：`qsc-101.webp`、`qsc-108.webp`、`qsc-123.webp`、`qsc-127.webp`，放在 Step 03／04。保留原始截圖、播放器時間與字幕，附來源及對應時間連結。

網站不呼叫圖像 API，沒有任何瀏覽器端金鑰或其他憑證。
