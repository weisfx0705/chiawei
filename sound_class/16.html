選頻方法對頻練習試音

現場錄音手冊 / WIRELESS AUDIO

Sennheiser G3無線麥克風設定

領夾接 SK，錄音機接 EK。兩台的頻段要相容，螢幕上的 MHz 要相同。

自動與手動設定 ↓練習調頻 ↗

頻率怎麼設？

SET 進選單或確認，▲▼ 選項目。

自動掃頻 到新場地時用

  1. 關閉待配對的 SK，讓現場其他使用中的發射器繼續工作。
  2. EK 選 Easy Setup → Scan New List。選可用的 Bank、Channel，按 SET 儲存。
  3. 打開 SK。EK 選 Sync，兩台紅外線窗相對，看到 ✓ 就對好了。

手動設頻 已有指定頻率時用

  1. 在 EK 選 Advanced → Tune，短按 SET。
  2. ▲▼ 調 MHz，按 SET 換到 kHz。每格 25 kHz，調好再按 SET 儲存。
  3. 在 SK 重做一次。兩台顯示相同 MHz 後，開口試音。
拿到的是 Bank／Channel？

兩台都進 Frequency Preset，選同一個 Bank 和 Channel，各按 SET，再核對 MHz。

想指定 U 裡的儲存位置？

在 Tune 長按 SET，先選 U 的 Channel，再輸入頻率。從原廠 Bank 直接進 Tune，會先切到 U.1。

同場多支麥 同頻段選同一個原廠 Bank，每支使用不同的空 Channel。

換你對頻。

EK 已設好。用 SK 的三顆按鍵調到同一頻率。

頻率是模擬值。實機請用現場分配的空頻率。

對好了，試錄十秒。

讓演員說最大聲的一句，再走到最遠的位置。戴耳機回放，聽有沒有破音或斷音。

RF 沒訊號

查電池、RF Mute 和兩台的 MHz。走遠才斷音時，檢查遮擋，用能壓住底噪的最低 Squelch 門檻。

有 RF，說話時 AF 不動

RF 看無線訊號，AF 看聲音。檢查 SK 的領夾插頭、MUTE 與 Sensitivity。

錄音太大或太小

先調 SK 的 Sensitivity，讓 AF PEAK 只在最響處閃一下。再用 EK 的 AF Out 配合錄音機的 MIC／LINE 輸入。
