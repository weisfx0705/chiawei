頻率怎麼設？

先確認兩台頻段相容。SET 確認，▲▼ 選項目。

自動掃頻 到新場地時用

  1. 只關閉待配對的發射器（子機），其他使用中的那幾組保持開機。
  2. 接收器（母機）選 Easy Setup → Scan New List，掃描現場找可用頻道。選好 Bank、Channel，按 SET 儲存。
  3. 打開發射器（子機）。接收器（母機）選 Sync，對準兩台紅外線窗，看到 ✓ 即完成。

練習幫第二位演員掃頻 →

手動設頻 已有指定頻率時用

  1. 接收器（母機）選 Advanced → Tune，短按 SET。
  2. ▲▼ 調 MHz，按 SET 換到 kHz。每格 25 kHz，調好再按 SET 儲存。
  3. 在發射器（子機）重做一次。兩台顯示相同 MHz 後，開口試音。
拿到的是 Bank／Channel？

兩台都進 Frequency Preset，選同一個 Bank 和 Channel，各按 SET，再核對 MHz。

想指定 U 裡的儲存位置？

在 Tune 長按 SET，先選 U 的 Channel，再輸入頻率。從原廠 Bank 直接進 Tune，會先切到 U.1。

練習手動調到同頻 →

同場多支麥 同頻段選同一個原廠 Bank，每支使用不同的空 Channel。

有 RF，卻收不到聲音？

先檢查領夾麥克風是否插牢。G3 子機和母機的 Advanced → Pilot Tone 原則上都保持 On，讓母機辨認子機。跨品牌配對才視相容性考慮關閉。

把子機交給演員前

先試好子機的 Sensitivity

子機還在手上時，先請演員用台詞裡最大聲的音量試講。用 Sensitivity 調整領夾麥克風或 LINE 訊號的輸入增益。AF PEAK 持續亮起時，把靈敏度往更負的 dB 值調，再試一次。

母機 AF Out 原則上維持 0 dB。先調子機的 Sensitivity，再確認錄音機的 MIC／LINE 輸入選擇和增益。電平還是配合不了時，最後才微調母機輸出。

避免演員誤觸靜音或改到設定

演員可能碰到子機的 MUTE 撥桿。交機前到 Advanced → Mute Mode 選 Disabled，避免撥桿切掉聲音。

AF 和 RF 的靜音有什麼差別？

AF On/Off 只關音訊，RF 照常發射。RF On/Off 會關掉無線發射。Disabled 停用靜音撥桿。

Auto Lock 會自動鎖定按鍵。看到 Locked 時，先按 SET，再按 ▲ 或 ▼ 叫出 Unlock?，最後按 SET 暫時解鎖。

聲音在哪一段出問題？

把子機的 AF PEAK 降下來，讓母機的 AF Out 留在 0 dB。

對好了，試錄十秒。

讓演員說最大聲的一句，再走到最遠的位置。戴耳機回放，聽有沒有破音或斷音。

RF 沒訊號

查電池、RF Mute 和兩台的 MHz。走遠才斷音時，先檢查身體或布景是否遮住訊號。若要確認母機的 Squelch，先關掉這組子機，選能壓住嘶聲的最低一檔，再開機走位試錄。

有 RF，說話時 AF 不動

RF 看無線訊號，AF 看聲音。檢查發射器（子機）的領夾插頭、MUTE 與 Sensitivity。

錄音太大或太小

先看子機的 Sensitivity，再查錄音機輸入。兩處都調過還配合不了，才動母機的 AF Out。低輸出較接近 MIC 電平，高輸出較接近 LINE 電平。
