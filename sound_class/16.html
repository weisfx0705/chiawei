Sennheiser G3無線麥克風設定

把領夾麥克風別好，打開兩台腰包。開拍前，你怎麼知道這句台詞真的進了錄音機？

領夾麥克風→ SK 發射器 ⇢ EK 接收器 → 錄音機

拿著機器跟做 ↓先練習對頻 ↗

實機操作

從空頻道，
到第一句台詞。

兩人一組。一人帶著 SK 走位，一人在 EK 和錄音機旁監聽。

SET 選取、確認或儲存
▲ ▼ 移動或改值
ON/OFF 在選單中短按可返回

  1. 從線材認出兩台腰包

    SK 的輸入接領夾麥克風，EK 的輸出接錄音機或相機。輕輕鎖緊 3.5 mm 接頭的螺環。在兩台機身確認型號與相容頻段，各裝兩顆 AA 電池，再把耳機接在最後要錄音的機器上。

  2. 把準備配對的發射器關掉，再讓 EK 掃頻

    在拍攝地點安置接收器，其他已在使用的無線系統照常運作。從 EK 按鍵進入下列路徑，查出當時空著的預設頻道。

    SET → Easy Setup → Scan New List

  3. 選 Bank、選 Channel，儲存後再開 SK

    用上下鍵找出有足夠空頻道的原廠 Bank，再選一個空 Channel。按 SET 看到 Stored。同頻段多組一起用時，統一用同一個原廠 Bank，每支演員麥分配不同的空 Channel。把演員名和 Bank／Channel 記在聲音報表。

  4. 用紅外線把設定傳給發射器

    開啟這一組 SK。在 EK 選 Sync，打開腰包電池蓋，讓兩台的紅外線窗近距離正對。EK 出現 ✓ 表示傳送完成。出現 × 就重新對準再試。核對兩台頻率相同，再看 EK 的 RF 格數。

  5. 先調發射器，再接收，最後聽回錄

    請演員說本場最大聲的一句。在 SK 的 Sensitivity 調整輸入，讓大聲處才接近滿格。若一直亮 AF PEAK，就往更負的 dB 調。然後用 EK 的 AF Out 配合錄音機的 MIC／LINE 輸入與增益，留出大笑或喊話的空間。

    讓演員轉身、坐下，走到最遠點。試錄十秒，停機回放，聽字尾有沒有失真、斷音或衣物摩擦，再決定能不能開拍。

片場排查

看哪一段
先失去訊號。

RF 是接收到的無線電強度，AF 是聲音電平。兩個表分開看，才能知道下一步該碰哪台機器。

EK 的 RF 沒反應

檢查 SK 的電池和 RF Mute，確認兩台頻段相容、頻率相同。靠近測試，重新 Sync，再沿預定走位拉開距離。

有 RF，說話時 AF 沒動

先看 SK 的 AF。若沒動，檢查領夾插頭、螺環與 Sensitivity。若 SK 有反應，再確認 MUTE、兩台的 Pilot Tone 設定，以及接到的是這位演員的那一組。

EK 有 AF，錄音機無聲或破音

檢查 EK 輸出線、錄音軌是否啟用、MIC／LINE 和錄音機增益。SK 已經爆音時，先降低發射端輸入靈敏度。若只有錄音機紅燈，才回頭調 EK 的 AF Out 或錄音機輸入。

靠近正常，走遠卻斷音

請演員走一遍，觀察身體遮擋、天線位置和 RF 格數。依原廠建議，關閉該組發射器後，讓 Squelch 從 Low 起調，採用足以抑制嘶聲的最低門檻。門檻太高會縮短有效距離。

機身選單速查
Mute Mode
在 SK 的 Advanced 裡設定撥桿。AF On/Off 切音訊，RF On/Off 切無線發射，Disabled 停用撥桿。
Pilot Tone
這組 G3 發射與接收端使用相符的導頻設定。Sync 會傳送頻率、名稱和 Pilot Tone 設定。
Auto Lock
交給演員前可鎖定按鍵。需調整時，按 SET，選 Unlock，再以 SET 確認。
Current List / Tune
Current List 可回看上一次掃描結果。換場重新掃描。Tune 為手調頻率，本練習使用原廠預設 Bank。
