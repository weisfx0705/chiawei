現場錄音手冊 / WIRELESS AUDIO

Sennheiser G3無線麥克風設定

發射器（子機）在演員身上，接領夾麥克風。
接收器（母機）在錄音室這端，接錄音機。

自動與手動設定 ↓練習調頻 ↗

頻率怎麼設？

先確認兩台頻段相容。SET 確認，▲▼ 選項目。

自動掃頻 到新場地時用

  1. 只關閉待配對的發射器（子機），其他使用中的那幾組保持開機。
  2. 接收器（母機）選 Easy Setup → Scan New List。選可用的 Bank、Channel，按 SET 儲存。
  3. 打開發射器（子機）。接收器（母機）選 Sync，對準兩台紅外線窗，看到 ✓ 即完成。

手動設頻 已有指定頻率時用

  1. 接收器（母機）選 Advanced → Tune，短按 SET。
  2. ▲▼ 調 MHz，按 SET 換到 kHz。每格 25 kHz，調好再按 SET 儲存。
  3. 在發射器（子機）重做一次。兩台顯示相同 MHz 後，開口試音。
拿到的是 Bank／Channel？

兩台都進 Frequency Preset，選同一個 Bank 和 Channel，各按 SET，再核對 MHz。

想指定 U 裡的儲存位置？

在 Tune 長按 SET，先選 U 的 Channel，再輸入頻率。從原廠 Bank 直接進 Tune，會先切到 U.1。

同場多支麥 同頻段選同一個原廠 Bank，每支使用不同的空 Channel。

換你對頻。

接收器（母機）已設好。用發射器（子機）的按鍵調到同一頻率。

頻率是模擬值。實機請用現場分配的空頻率。

對好了，試錄十秒。

讓演員說最大聲的一句，再走到最遠的位置。戴耳機回放，聽有沒有破音或斷音。

RF 沒訊號

查電池、RF Mute 和兩台的 MHz。走遠才斷音時，檢查遮擋，用能壓住底噪的最低 Squelch 門檻。

有 RF，說話時 AF 不動

RF 看無線訊號，AF 看聲音。檢查發射器（子機）的領夾插頭、MUTE 與 Sensitivity。

錄音太大或太小

先調發射器（子機）的 Sensitivity，讓 AF PEAK 只在最響處閃一下。再調接收器（母機）的 AF Out，配合錄音機的 MIC／LINE 輸入。
