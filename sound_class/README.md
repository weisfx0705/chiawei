# 聲音課程互動教材

義守大學電影與電視學系陳嘉暐老師的網頁教材，涵蓋數位音效設計與影視錄音實務。以互動圖解、聲音試聽、操作練習與課後回饋協助學生理解聲音製作。

## 課程入口

| 入口 | 內容 |
| --- | --- |
| [數位音效設計](index.html) | 監聽音量、基礎聲學、電影聲音部門、EQ、效果器、麥克風與響度 |
| [影視錄音實務](index2.html) | 同步錄音、現場成音、錄音流程、聲道與 PolyWAV，以及錄音團隊與器材教材 |

## 獨立教材

| 教材 | 說明 |
| --- | --- |
| [同步錄音團隊](sound-recording-presentation/README.md) | 26 頁互動簡報、訊噪比試聽、檢查表與聲音報表練習 |
| [Zoom 錄音機自學頁](h4n_eseential/README.md) | H4n 與 H4essential 的機身辨識、接線、錄音與交檔流程 |
| [聲音球體 Sound Spheres](sound-spheres/README.md) | 從內在念頭到外在聲景的分層聆聽與筆記練習 |

各教材的操作方式與素材來源，請見對應 README 或頁面中的來源說明。

## 本機預覽

在儲存庫根目錄執行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8765/sound_class/`；錄音實務入口為 `http://127.0.0.1:8765/sound_class/index2.html`。按 Ctrl+C 停止伺服器。

不需要安裝套件或執行建置。多數編號單元透過 CDN 載入 React、Babel 或 Tailwind CSS，預覽時仍需連網；外部影片與 Google 表單也需要網路。

## 檔案與維護

- `index.html`、`index2.html`：兩門課的導覽入口。
- `1.html` 至 `7.html`：數位音效設計入口所使用的單元。
- `8.html` 至 `13.html`：影視錄音實務入口所使用的單元。
- `sound/`：課程音訊素材。
- 三個教材子資料夾：各自保留頁面、樣式、互動程式與素材。

部署時保留資料夾結構與相對路徑，可隨主網站放在 GitHub Pages 等靜態主機。新增或調整單元時，也要核對兩個導覽入口的連結。

部分頁面是教學模擬，不代表實際硬體量測或錄音結果。播放音訊前先降低音量，依頁面提示開始試聽。
