初階同步錄音3｜H4n 按鈕與基礎設定校正稿
錄製年份：2021
講者：陳嘉暐老師

00:00:08
接下來講 H4n 的組裝。

00:00:12
先打開電池蓋。電池槽裡有一條拉帶，裝電池時讓拉帶壓在電池下方。之後要取出電池時，拉一下拉帶就比較容易拿出來。

00:00:31
H4n 使用兩顆 AA 三號電池。課程使用時請選鹼性電池，英文是 alkaline。鹼性電池比較能支撐需要較高電量的電子產品，所以現場使用前要先確認電池種類。

00:00:54
機身上有 STAMINA 省電開關。本課程採強制關閉規則。開啟 STAMINA 後，可能會影響 phantom power，也會限制錄音格式。影視錄音要保留後期處理空間，請不要為了省電開啟這個模式。

00:01:34
SD 卡插槽在機身側邊。H4n 的年代較早，錄影當下是 2021 年。H4n 支援 SD / SDHC 卡，官方手冊規格為 16MB 到 32GB。避免使用 SDXC；如果卡片讀不到，請改用 H4n 支援的 SD / SDHC，並在機器內格式化。

00:02:30
開機後，按右側 MENU。使用滾輪往下移動，進入需要的選項。準備錄音前先做幾個基礎設定。

00:02:47
第一個是 SD CARD → FORMAT。格式化的目的，是讓卡片變成 H4n 可以穩定讀寫的格式。格式化會清除卡片內容，執行前先確認檔案已經備份。

00:03:02
回到 MENU，選擇 REC，設定錄音格式。陳嘉暐老師的課程標準是 48kHz / 24bit 以上。以 H4n 的課程流程來說，請使用 48kHz / 24bit。

00:03:29
如果按的是 MIC，H4n 會使用上方內建的 XY 麥克風。這適合隨身帶出去錄環境音、近距離訪談、簡單人聲，或有人彈吉他之類的聲音。影視系同學更常拿它錄環境音與空場聲。

00:03:52
如果要接 shotgun 麥克風與無線麥克風，輸入來源要選到底部 INPUT 1 / INPUT 2。實務上可以把 shotgun 接 INPUT 1，把無線接收器接 INPUT 2，再分別檢查兩路聲音。

00:04:00
回到 MENU，進入 INPUT。首先確認 PHANTOM POWER。像 shotgun 這類電容式麥克風需要 phantom power 時，要依麥克風需求開啟，常用設定是 +48V。

00:04:17
Phantom power 不使用時盡量關閉。它會耗電，也可能在不適合的器材上造成風險。需要時打開，不需要時關掉。

00:04:35
INPUT 裡有兩個重要選項：1/2 LINK 與 MONO MIX。本課程的雙麥克風拍攝流程，兩個都先關閉。

00:04:41
MONO MIX 會把第一軌和第二軌混在一起，變成同一個聲音。這樣 shotgun 和無線麥克風就分不開，後期調整會很麻煩。因此雙麥拍攝時請關閉 MONO MIX。

00:05:02
1/2 LINK 會讓第一軌與第二軌的調整連動。例如 INPUT 1 增加五個單位時，INPUT 2 也跟著增加。Shotgun 應該有自己的音量，無線麥克風也應該有自己的音量，所以 1/2 LINK 請關閉。

00:05:30
基礎設定到這裡差不多。接著示範使用內建麥克風錄音。

00:05:38
輕按一次 REC 鍵時，H4n 會進入 standby。這時還沒有正式開始錄音，但耳機已經可以聽到聲音。

00:05:46
耳機孔在機身側邊。VOLUME 控制耳機音量，也就是你聽到的大小。

00:05:56
要記得，聽到的音量和錄進檔案的音量是兩件事。耳機音量調到很小，錄音仍然可能很大；耳機音量調很大，也不代表錄進去的聲音足夠。

00:06:17
錄進檔案的大小要看 REC LEVEL。REC LEVEL 往下降，錄音音量會變小；往上升，錄音音量會變大。

00:06:36
使用 H4n 時，對話音量建議大致抓在 -12 dB 左右，尤其是現場對白。不要錄得太小，否則後期會更難處理。

00:07:03
再次按 REC 才開始正式錄音。錄音時可以用測試聲確認，例如「1、2、3」。螢幕上會顯示檔號，例如 STE-000。

00:07:09
錄完按 STOP。接著按 PLAY 回放，確認剛才的聲音真的錄進去了。再錄下一個檔案時，檔號會往後增加，例如從 STE-000 變成 STE-001。

校正重點
1. 去除口語填充詞，保留教學指令。
2. SD 卡段落以 H4n 官方手冊規格校正為 SD / SDHC 16MB-32GB，避免把未核實的速度等級寫成絕對規則。
3. 以學生自學語氣整理操作步驟，並保留課程現場使用規範。
