# 對誰好？AI 時代的思考練習

陳嘉暐老師的五週互動課程教材。從理解、判斷、主權、作者責任到知止與傳承，透過日常案例和課堂練習，整理人與 AI 合作時仍需要自己承擔的選擇。

[網站入口](https://weisfx0705.github.io/chiawei/know-when-to-stop/) · [主專案說明](../README.md)

## 學習內容

| 週次 | 主題與練習 |
| --- | --- |
| 01 理解 | 以三色標記分辨事實、推論與價值 |
| 02 判斷 | AI 權限分級、找出被平均值遮住的人 |
| 03 主權 | 七秒限時決策與暫停協議 |
| 04 作者 | 寫作貢獻地圖、找回自己的聲音 |
| 05 傳承 | 停頓倒數與 AI 傳承宣言 |
| 期末整合 | 整理並複製「我的 AI 決策憲章」 |

可用頂端導覽與頁面上下按鈕移動。依各練習的提示操作、輸入札記，再整理期末憲章。教材本身不呼叫 AI 服務；需要 AI 產生文章的活動，請將頁面提示複製到自己使用的 AI 工具，完成後貼回教材。

## 本機預覽

從儲存庫根目錄執行：

```sh
cd know-when-to-stop
python3 -m http.server 8000 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8000/`，按 Ctrl+C 停止。HTML、CSS 與 JavaScript 都在 `index.html`，插圖位於 `assets/`，無須安裝套件或建置。發布時保留這兩者的相對位置即可。

## 資料保存與編輯

札記與憲章欄位透過 `localStorage` 保存在目前瀏覽器；清除網站資料、換裝置或換瀏覽器後不會自動帶入。部分練習狀態只保留在當次頁面，建議完成後複製需要留存的文字。

修改教材內容與互動請編輯 `index.html`；更換插圖時同步檢查圖片的 `src` 與 `srcset`。複製功能依賴瀏覽器剪貼簿權限，建議使用 HTTPS 或 localhost；無法複製時可手動選取文字。
