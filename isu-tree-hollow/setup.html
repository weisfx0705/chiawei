連接 Google 收件

網頁可放在 GitHub Pages。只需連接一次 Google 收件程式，學生就能在同一頁送出文字與錄音。

  1. 開啟 Google Apps Script，建立新專案，貼上以下程式碼。
  2. 儲存後，選擇 setupTreeHollow 函式並執行。第一次需要你確認 Google 的權限。它會建立新的表單、輔導紀錄試算表與私人音檔資料夾。
  3. 選擇「部署 → 新增部署 → 網頁應用程式」，以你自己執行，存取者選「所有人」。這是只供提交的收件入口；學生無法藉此讀取紀錄。
  4. 複製部署完成的 /exec 網址，貼在下方。下載設定檔後，以它覆蓋此資料夾中的 config.js。
  5. 用本機頁面送出一筆測試，確認輔導紀錄表出現資料，錄音能以你的 Google 帳號播放，再上傳網站。

收件程式

這段程式不寄 Email、不自動轉寫、不讀取其他 Drive 檔案。Google 授權介面仍可能列出 Drive、表單與試算表的完整服務權限，請檢視後自行確認。

產生網站設定

GitHub Pages

上傳 index.html、styles.css、app.js、config.js、assets/ 和 .nojekyll。所有資源都使用相對路徑，可放在既有專案的子資料夾。

收件程式預設接受 https://weisfx0705.github.io 與本機預覽。若改用其他網域，請修改 Code.gs 的 allowedOrigins，再建立新版部署。

手機請用 Safari 或 Chrome 開啟正式 HTTPS 網址。LINE 內建瀏覽器若無法錄音，可改到外部瀏覽器，或使用上傳音檔。
