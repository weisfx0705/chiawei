# 影視課程島｜高中生探索版

## 目前正式流程（2026-11-01，journeyVersion 2）

**主島 → 任選三個不同職能島 → 精神時光屋 → 畢業首映殿堂。**

先完成主島，才能體驗職能島。第三個不同職能完成時，時光屋的實體光環、門框、光源及標籤會亮起，並在領獎後直接邀請前往，無需回主島。時光屋解鎖前所有入口均顯示目前缺少的步驟。進入時光屋觀摩三部隨機作品後，按「靈感收集完成，前往畢業首映」才記錄 `timehouseComplete` 並解鎖殿堂。首映星環與 150 XP 仍只發放一次；另五個職能島可繼續探索。

舊存檔保留 XP 與裝備，但不假定已完成新增的時光屋交接步驟；符合主島＋三個職能者會收到一次新版路徑提示。左上角 logo 以新分頁連至 https://filmtv.isu.edu.tw/，不再充當回主島按鈕。以下歷史更新紀錄中的舊解鎖條件，以本節為準。


## 體驗模式／闖關模式（2026-11-01）

首頁改為兩種玩法，遊戲中可隨時用右上角「🧭 體驗模式／🎮 闖關模式」切換；兩種模式共用同一份進度，路線不變：**主島 → 任三座職能島 → 精神時光屋 → 畢業首映**。

- **體驗模式**：原本的每島三選一創作選擇。
- **闖關模式**：主島仍是三選一；八座職能島各有一個常見玩法的小遊戲，課程介紹、代表課程與學長姊作品仍在島嶼面板上方。過關後按「領取裝備」才算完成該島；闖過三座即點亮時光屋，可繼續挑戰其他島。最佳星等存在 `state.arcade`，冒險卡會顯示。

| 島嶼 | 遊戲 | 經典玩法 | 對應課程 |
|---|---|---|---|
| 導演編劇 | 分鏡翻牌大考驗 | 記憶翻牌（景別名稱 ↔ 畫面） | 分鏡設計 |
| 攝影燈光 | 點亮片場 | Lights Out（3×3、4×4，附提示） | 影視燈光 |
| 美術造型 | 穿幫大搜查 | 找不同 | 電影美術設計 |
| 聲音錄音 | Boom 收音不穿幫 | 拖曳定位：畫框外最靠近嘴巴（改編自課程教材〈電影同步錄音基本態度〉） | 影視錄音實務 |
| 剪輯特效 | 節拍剪接台 | 節奏遊戲 | 影視剪輯 |
| 製片管理 | 製片補給大作戰 | 接物遊戲（綠圈補給 +1、紅圈風險 −❤） | 影視製片管理 |
| 行銷發行 | 找對觀眾打地鼠 | 打地鼠 | 影視數位發行 |
| 影視研究 | 影史快問快答 | 問答（每題附解說） | 電影理論與美學 |

新增檔案：`arcade.js`（遊戲外框與八個遊戲，Web Audio 合成音效）、`studio.css`（介面皮膚、雙模式首頁、遊戲樣式）。兩者已加入 `build_assets.py`，修改後一樣執行 `python3 build_assets.py`。介面改版只換視覺（色彩、面板、按鈕、各島主題色），版面位置與既有 DOM ID 不變。遊戲支援滑鼠、觸控與鍵盤，並在「減少動態效果」設定下停用裝飾動畫。

以 `film-island` 為起點建立的獨立副本，原版未修改。

## 使用方式

雙擊 `open.command`，或在本資料夾執行 `python3 -m http.server 8779 --bind 127.0.0.1`。成品不需要 npm 或安裝依賴。修改原始 JS／CSS 後，執行 `python3 build_assets.py` 更新 `game.js`、`game.css` 與入口版本。請勿直接編輯產出的 bundle。將本資料夾完整放到靜態網站即可使用。

## 內容原則

共同必修主島＋八個專業方向是主體；短片、金種子影展、海外創作、畢業製作是實作亮點。每個方向三門代表課，以原專案 `cohorts.js` 的 115 學年度資料核對課號、課名與必選修。省略學分、年級分層與個別修課勾選；方向不是正式分組或先修關係。學習說明是白話導覽詮釋。

新版遊戲紀錄儲存在本機瀏覽器的 `film-island-playground-v1`，與原版修課紀錄、先前靜態探索收藏分開。主島任務 50 XP，每個專業方向首次完成 100 XP，探索三個方向後可以回主島完成首映體驗並獲得 150 XP；重玩不重複發放。八件裝備可分別穿脫，首映星環為第九件可見獎勵。XP 與徽章純屬遊戲體驗，不代表學分、能力認證或實際影展獲獎。

全螢幕 3D 場景包含飛行角色、展開式滑翔翼、飛行軌跡、摩天輪、熱氣球、各島系所招牌與角色工作證。三種片場光線及聲音任務直接提供感官互動；使用系統「減少動態效果」時縮短飛行並停用裝飾動畫和灑花。正式 logo 沿用原版 `logo.png`。

之前較靜態的設計保留在工作區 `output/explore-editorial-backup/` 供參考。預告片點選才載入 YouTube，切換作品及關閉視窗會移除播放器，並保留 YouTube 備援連結。WebGL 不可用時仍可用方向按鈕閱讀課程。
